# Estudo de Caso - Vetores e Matrizes
 
Estudo de caso desenvolvido durante a disciplina de **Estrutura de Dados**, do curso de **Análise e Desenvolvimento de Sistemas**.
 
O exercício implementa a estrutura **Matriz** usando um **vetor** como estrutura de armazenamento, com operações para dimensionar, zerar, imprimir, adicionar, buscar elementos e somar matrizes.
 
## Tecnologias
 
- Linguagem C
